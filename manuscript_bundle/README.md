# Manuscript bundle (PRD §14B)

Paper-facing figures, tables, frozen configs, manifests, aggregated metrics, milestone reports, and provenance.

Subdirectories are created by `esl.experiments.canonical_io.ensure_manuscript_bundle_layout` (used in milestone smoke tests and future bundling scripts).

- ESL registry smoke: `tests/test_experiment_registry_milestone1.py`
- PPO baseline (Milestone 2A): run `git submodule update --init third_party/PPO-PyTorch`, install `requirements-ppo.txt` (`torch`), then `tests/test_ppo_baseline_milestone2a.py`
- Milestone reports: `reports/milestone_1_smoke`, `reports/milestone_2a_ppo`, `reports/milestone_2b_kmeans`, `reports/milestone_2b_fcm`, index `reports/milestone_2b_clustering/README.md`, `reports/milestone_3/MILESTONE_STATUS.md`, …
- **Milestone 3 (core ESL validation):** `ESL_PUBLICATION_DPI=300 python3 -m esl.experiments.milestone3_pack --out-root runs/milestone3_smoke --manuscript-bundle manuscript_bundle` — sparse **p_obs** sweep, **Q** (`prototype_update_every`) sweep, freeze-θ diagnostic; batch side **K-means + FCM only** (`--clustering-only-baselines` on `sparse-pobs-sweep` / `q-recovery-sweep`). Same flags via `python -m esl.experiments sparse-pobs-sweep …` / `q-recovery-sweep …`.
- **Milestone 4 (paper-grade reproduction):** multi-seed sweeps (default 10 seeds, 5000 rounds per sweep), mean ± std and 95% CI for the mean, CI bands on main figures, **init_noise** and **K** robustness. Smoke: `python3 -m esl.experiments.milestone4_paper --smoke --out-root runs/m4_smoke --manuscript-bundle manuscript_bundle`. Full paper run (long): omit `--smoke` and optionally set `--rounds-sparse`, `--rounds-q`, `--rounds-init`, `--rounds-k` in the 3000–10000 range. Equivalent: `python3 -m esl.experiments milestone4-paper --out-root runs/milestone4_paper --manuscript-bundle manuscript_bundle` (add `--smoke` for CI). Report: `reports/milestone_4/MILESTONE_STATUS.md`.
- **Milestone 5 (strategic adaptation):** heterogeneous IPD (focal ESL vs AC/AD/TFT bots), independent PPO focal + clustering+logit BR baselines, K=1 ablation, multi-seed mean and 95% CI, publication figures. Smoke: `python3 -m esl.experiments milestone5-pack --smoke --skip-ppo --out-root runs/m5_smoke --manuscript-bundle manuscript_bundle`. Full run needs `third_party/PPO-PyTorch` for PPO (omit `--skip-ppo`). Report: `reports/milestone_5/MILESTONE_STATUS.md`.
- **Milestone 6 (mechanism & robustness):** payoff vs MCE correlation, ``K_model`` misspec vs fixed ``K_true=2`` metrics, adaptation ``p_obs`` stress, uniform-belief ablation (``belief_updates_enabled=False``), optional matching pennies. Smoke: `python3 -m esl.experiments milestone6-pack --smoke --out-root runs/m6_smoke --manuscript-bundle manuscript_bundle`. Add `--matching-pennies` for optional exp5. Report: `reports/milestone_6/MILESTONE_STATUS.md`.
- **Milestone 7 (paper + manuscript):** frozen full runs for M4–M6 (`esl/experiments/configs/milestone7_frozen.json`), statistical audit, **main/** vs **appendix/** staging, `EXPERIMENT_REPORT.md`, captions/summaries, readiness note. Smoke: `python3 -m esl.experiments milestone7-paper --smoke --out-root runs/m7_smoke --manuscript-bundle manuscript_bundle`. Full paper: omit `--smoke` (long run).
- **Milestone 8 (camera-ready):** after Milestone 7 staging, run `python3 -m esl.experiments milestone8-camera-ready --manuscript-bundle manuscript_bundle` to produce **fig1.png–fig5.png**, `figure_index.json`, rewritten claim→figure→evidence `EXPERIMENT_REPORT.md`, cleaned captions, one-line takeaway in `text/main/`, and appendix-only robustness figures/tables. No re-runs.
- **Milestone 9 (submission hardening):** after Milestone 8, run `python3 -m esl.experiments milestone9-submission --manuscript-bundle manuscript_bundle` (optional `--min-fig-bytes` for full assets) to assemble `submission_bundle/paper/` and `submission_bundle/supplementary/`, verify fig1–fig5 + captions, write `abstract_refined` / `NOTATION_GLOSSARY.md`, a ten-minute `reports/milestone_9/REVIEWER_SIMULATION.md`, `ACCEPT_REJECT_RISK.md`, and `SUBMISSION_CHECKLIST.md`. No re-runs.

See `EXPERIMENT_REPORT.md` for the final experiment narrative once milestones complete.

**Generate `main/figures/fig1.png`–`fig5.png` locally (smoke, fast):**  
`MPLBACKEND=Agg python3 -m esl.experiments milestone7-paper --smoke --out-root runs/m7_smoke --manuscript-bundle manuscript_bundle` then  
`MPLBACKEND=Agg python3 -m esl.experiments milestone8-camera-ready --manuscript-bundle manuscript_bundle`.

**Resume after M4 completes (reuse M4 + finished M5 cells):** `scripts/resume_m7_after_m4.sh` (or `OUT=runs/m7_full … milestone7-paper --skip-m4-if-ready --m5-resume-skip-complete`). Incomplete M5 directories (e.g. crashed mid-`clustering_kmeans`) are removed and re-run.

**Full paper validation (no smoke) + diagnostics:** `export ESL_PUBLICATION_DPI=300` then run `scripts/run_full_paper_validation.sh` (long). `run_milestone7_paper` without `--smoke` **refuses** to start unless the frozen JSON satisfies seeds ≥10, M4 rounds ∈ [5000,10000], M5 ∈ [2000,5000], M6 ∈ [1000,3000], and `ESL_PUBLICATION_DPI` is exactly **300** (`esl/experiments/paper_run_contract.py`). **Progress:** full runs print `[progress] …` steps per seed/sweep; a heartbeat every `ESL_PROGRESS_HEARTBEAT_SEC` seconds (default **120** in the script; set to **0** to disable the timer thread). After M7, the script runs `figure-diagnostics`; **stop before M8/M9** until you confirm figure decisions.
